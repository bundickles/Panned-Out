# Panned Out

Panned Out is a meal planning app designed to make an everyday task of meal planning easy. It centralizes meal organization, recipes, nutrition information, and even the mundaneness of creating a shopping list

## Tech Stack

### Frontend
- React
- Vite
- Javascript
- CSS

### Backend
- Java

- Recipe Information
